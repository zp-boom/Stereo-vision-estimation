# Monocular & Stereo Depth Estimation for Robot Perception

## 🚀 模块一：单目测距闭环 Demo (YOLO + Depth Anything V2)

**目标**：结合目标检测的语义信息与单目深度估计的相对深度，输出“目标类别 + 物理距离”的直观结果。

### 核心实现逻辑
1.  **检测**：使用 YOLOv8n 提取图像中的目标（如车辆、行人）边界框。
2.  **深度估计**：使用 Depth Anything V2 生成全图深度图。
3.  **信息融合与抗干扰**：为了规避边界框边缘包含背景（如马路、树木）导致测距偏大，代码中**裁剪了检测框中心 50% 的区域**，提取该区域的深度**中值**作为目标的最终距离估计。
4.  **可视化**：将距离信息渲染在图像上。

### 局限性反思
单目深度模型（如 Depth Anything）存在**尺度模糊（Scale Ambiguity）**，当前输出的绝对距离依赖于模型本身的泛化尺度。若需高精度应用，需结合双目几何或 IMU/雷达进行尺度对齐。

## 📐 模块二：双目立体视觉与测距 (OpenCV SGBM)

**目标**：利用 KITTI 校正后的左右图像，通过传统 SGBM 算法计算视差，恢复场景的绝对物理尺度。
**原理**：基于双目几何公式 \(Z = \frac{f \cdot B}{d}\) ，其中 \(f \cdot B\) 由相机标定参数确定（本实验取 `384.38148`），\(d\) 为视差。

### BlockSize 参数对比实验
控制其他变量（`P1=200`, `P2=800`, `numDisparities=192` 等），仅改变匹配窗口大小 `blockSize`。

| 指标 | blockSize=5 | blockSize=9 |
| :--- | :--- | :--- |
| **有效视差比例** | **80.28%** | 76.00% |
| **全图有效像素视差中位数** | 18.06 px | 18.62 px |
| **y=220 局部视差中位数** | 16.00 px | 15.62 px |
| **y=220 距离估计** | 24.02 m | 24.60 m |
| **y=300 局部视差中位数** | 40.00 px | 40.00 px |
| **y=300 距离估计** | 9.61 m | 9.61 m |

### 实验观察与工程反思
*   **观察**：`blockSize=9` 在路面和物体边缘产生了更多零散的无效像素，有效视差比例下降 4.28%。
*   **结论**：在当前分辨率和场景下，增大窗口并未带来显著精度提升，反而丢失了细节，`blockSize=5` 综合表现更好。
*   **局限性**：有效视差比例仅代表算法给出结果的像素占比，**不代表准确率**。后续计划引入带真值深度的数据集（如 KITTI 深度补全数据）计算 RMSE 等误差指标。

## 🧠 模块三：Monodepth2 自监督模型复现与反思

**目标**：复现经典的自监督单目深度估计模型 Monodepth2，并验证不同 Backbone 的性能表现。

### 关键踩坑与修复 (版本兼容)
在 2024 环境下复现 2019 年代码，解决 13 处 API 变动引发的报错：
*   `model_urls` 移除 -> 改用 `ResNet18_Weights.IMAGENET1K_V1.url`
*   `Image.ANTIALIAS` 移除 -> 改用 `Image.Resampling.LANCZOS`
*   `np.int` 移除 -> 改为内置 `int`
*   迭代器 `.next()` -> 改为 `.__next__()`
*(详细修复记录见代码注释)*

### 核心实验对比：数据泄漏与泛化能力

**实验一：发现数据泄漏**
最初使用同一段路（`drive_0001`）同时作为训练集和验证集，10轮时 Abs Rel 降至 0.128。但这是**指标虚高**，验证集包含了训练集场景，无法代表真实泛化能力。

**实验二：真实泛化测试（Backbone 权衡）**
改用多路段训练，独立路段验证（`drive_0005`）。

| Backbone | 参数量 | Abs Rel (越低越好) | RMSE | δ<1.25 (越高越好) | 训练速度 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| ResNet18 | 1100万 | 0.301 | 7.839 | 0.374 | 快 |
| ResNet50 | 2500万 | **0.226** | **5.633** | **0.539** | 慢约 2x |

*   **工程反思**：ResNet50 显著提升了精度，但付出了近 2 倍的训练时间代价。在机器人等实时性要求高的边缘端部署时，需要考虑 TensorRT 量化或选用轻量化 Backbone。
