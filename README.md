## 双目视差与测距：OpenCV SGBM

### 实验目标

使用 KITTI Raw 校正后的左右图像，通过传统立体匹配算法 SGBM 计算视差，并根据相机标定参数估计场景深度。

### 方法简介

SGBM（Semi-Global Block Matching，半全局块匹配）通过比较左右图像中的对应区域，估计每个像素的水平视差。对于已校正的双目图像，深度可由下式计算：

$$
Z = \frac{fB}{d}
$$

其中，$f$ 为焦距，$B$ 为左右相机基线，$d$ 为视差。视差越大，估计距离越近；视差越小，估计距离越远。

本实验使用 KITTI Raw 数据集 `2011_09_26_drive_0001_sync` 的 `image_02` 和 `image_03` 图像。图像尺寸为 `1242 × 375`，根据对应标定参数使用 $fB = 384.38148$ 像素·米进行深度换算。

### SGBM 参数

| 参数 | 设置 | 说明 |
|---|---:|---|
| `minDisparity` | 0 | 最小搜索视差 |
| `numDisparities` | 192 | 搜索视差范围，设置为 16 的倍数 |
| `blockSize` | 5、9 | 匹配窗口大小，本实验比较的变量 |
| `P1` | 200 | 对相邻像素小幅视差变化的平滑惩罚 |
| `P2` | 800 | 对较大视差变化的平滑惩罚 |
| `uniquenessRatio` | 10 | 匹配不够明确时舍弃结果的阈值 |
| `speckleWindowSize` | 100 | 过滤小块孤立视差区域 |

本实验固定 `P1`、`P2` 和其他参数，只改变 `blockSize`，以观察匹配窗口大小的影响。OpenCV 的 SGBM 参数说明见[官方文档](https://docs.opencv.org/4.x/d2/d85/classcv_1_1StereoSGBM.html)。

### `blockSize` 对照结果

| 指标 | `blockSize=5` | `blockSize=9` |
|---|---:|---:|
| 有效视差比例 | 80.28% | 76.00% |
| 有效像素视差中位数 | 18.06 px | 18.62 px |
| y=220 局部视差中位数 | 16.00 px | 15.62 px |
| y=220 距离估计 | 24.02 m | 24.60 m |
| y=300 局部视差中位数 | 40.00 px | 40.00 px |
| y=300 距离估计 | 9.61 m | 9.61 m |

局部数据取自图像约 `x=345:356`、`y±5` 的 `11 × 11` 像素区域。

### 实验观察

- `blockSize=9` 的视差图在路面和区域边缘出现了更多零散的无效像素；有效视差比例比 `blockSize=5` 低 4.28 个百分点。
- 两个选定区域的距离估计变化较小，其中 y=300 的估计相同。
- 该结果说明，在当前图像和参数设置下，增大匹配窗口没有带来明显的视觉改善。

### 实验限制

本实验没有使用真值深度进行误差评估，因此不能据此判断哪组参数的测距精度更高。有效视差比例表示成功得到视差的像素占比，不等同于准确率。全图中位数分别基于各自的有效像素集合，像素集合不同，不能视为逐像素误差比较。
